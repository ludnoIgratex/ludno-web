Статус: реализованы и проверены локально. Не закоммичены и не опубликованы. Данные Search Console после этих изменений ещё не обновлялись.

## Старые адреса и Strapi

Полная выгрузка Search Console содержит 139 URL с 404. На локальном production-сервере после исправлений **90 из 139** доходят до ответа 200. Результаты по каждому адресу: [gsc-404-resolution-2026-09-23.json](./gsc-404-resolution-2026-09-23.json). Это проверка подготовленной версии, не действующего сайта.

Оба адреса с soft 404 — `/map/playlet-solution` и `/map/tramptec-solution` — теперь перенаправляются на соответствующие страницы решений, конечный ответ 200.

Смена числового ID подтверждена сопоставлением устойчивого `documentId` в текущем каталоге и резервной копии PostgreSQL от 28 августа. Восстановлены четыре перехода:

| Старый ID | Текущий ID | Товар |
| --- | --- | --- |
| 2180 | 2496 | Дорожные знаки |
| 2076 | 2497 | Теневой навес |
| 2476 | 2485 | Рукоход |
| 2469 | 2484 | Угловая скамья |

Сборка сохраняет историю URL карточек, проектов и статей по `documentId`. При смене ID или названия старые адреса перенаправляются сразу на последний опубликованный адрес без цепочки. История хранится в CI-кеше и Docker-образе; при отсутствии кеша восстанавливается из предыдущего образа. Исходная история опубликованных карточек включена в репозиторий. Проверяется конфликт повторного использования ID разными документами.

Важно: это сохранение доступности прежних URL через 301 после следующей сборки сайта. Сама CMS и её числовые ID не изменены. Неопубликованные промежуточные версии между сборками не попадают в историю.

Из оставшихся 49 адресов:

- 46 ссылок на старые карточки: соответствие текущим товарам не установлено по доступной резервной копии. Для восстановления необходим более ранний архив с этими ID либо подтверждённая таблица соответствий. Одинаковое название товара недостаточно для перенаправления.
- `/$` и `/&`: мусорные адреса, сохраняют корректный 404.
- `/uploads/IMG_1148_aedce880de.HEIC`: отсутствующий старый файл, сохраняет 404; восстановление оригинала не выполнено.

Внутренние ссылки CMS на существующие товары приведены к актуальным URL. Удалённые товары в исторических текстах остаются текстом без битой ссылки. Исправлены старые категории, ссылки с ошибочными суффиксами и варианты транслитерации.

## Индексация и содержание

- У фильтров каталога исправлен canonical; `noindex, follow` сохранён. 188 исключённых URL из старого отчёта не означают 188 страниц, которые следует открыть для поиска.
- Для индексируемых страниц сборка проверяет соответствие canonical, отсутствие noindex и наличие файла для каждого URL карты сайта.
- В карточках товаров артикул добавлен в заголовок, размеры показаны независимо от наличия группы, фактические характеристики включены в description и структурированные данные. Это помогает различать похожие модели, но выбор canonical со стороны Google после переобхода ещё не проверен.
- На главной добавлены прямые ссылки на категории оборудования, в карточках — подходящие тематические посадочные.
- На 16 посадочных оборудования добавлены блоки подходящих проектов. Связи выбираются из CMS, с редакционным подбором по описаниям проектов при отсутствии связей. Блок обозначен как примеры похожих сценариев, без утверждения, что конкретная карточка товара использована в проекте.

Статусы «просканирована/обнаружена, но не проиндексирована» не устранены автоматически: требуется публикация, переобход и последующая оценка качества/индексации. Оставшиеся шаблонные посадочные не заполнялись в рамках этих технических исправлений.
