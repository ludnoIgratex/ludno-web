зависит от брендовых запросов и главной страницы. Приоритет: восстановить полезные

### P1. Старые адреса, которые до сих пор возвращают 404

Подтверждено HTTP-проверкой:

- `/$` — есть 10 исторических кликов GSC; нужно найти источник ошибочной ссылки.
- `/map/kinetics-solution` — итоговый адрес со слешем возвращает 404.
- `/card/1845/kachalka-na-pruzhine` — 404 после перехода на адрес со слешем.
- `/card/1553/domik-malyi` — 404 после перехода на адрес со слешем.
- `/card/2476/rukohod/` — 404.

Другие примеры из GSC, пока без отдельной HTTP-проверки:
`/card/1495/gorka-otdelnostoyashchaya`, `/card/1563/ostrovok-na-pruzhinah-kruglyi`,
`/card/828/bashnya-bolshaya`, `/card/1934/pesochnica-s-kryshkoi`,
`/card/1523/igrovoi-komleks`.

Действие: сопоставить старые ID актуальному каталогу. Если товар существует —
восстановить карточку или поставить постоянный редирект на её точный новый адрес.
Для удалённого без замены товара оставить корректный 404/410, убрать внутренние
ссылки и исключить из sitemap. Не перенаправлять все ошибки на главную.
В Метрике также зафиксировано 198 просмотров заголовка «Страница не найдена»;
связать их с конкретными входами и источниками — отдельная проверка.
[Как Google обрабатывает HTTP-статусы](https://developers.google.com/crawling/docs/troubleshooting/http-status-codes).

### P1. Разделить фильтры и самостоятельные поисковые посадочные

Живые `/products/all/`, `/products/Кинетикомоторные-площадки/` и
`/products/Детские-сады/` возвращают 200 с `noindex, follow` и canonical на
`/products/`. `/search-results/` тоже закрыт noindex. Это соответствует текущей
логике каталога, а не случайной недоступности сайта для Google.

Для продвижения направлений использовать отдельные содержательные страницы:
уникальные ответы на запрос, подходящие товары, реальные проекты, ссылки
на каталог и понятное контактное действие. Проверенные `/lazatelnye-kompleksy/`
и `/detskie-gorki/` уже возвращают 200, self-canonical и не закрыты meta robots.
Отсутствие запрета не гарантирует индексацию.

Не снимать noindex со всех комбинаций фильтров. Пересмотреть canonical на общий
каталог там, где содержимое существенно отличается: canonical предназначен
для дублей, noindex — для исключения из поиска. Внутренние ссылки и sitemap
должны последовательно указывать на выбранные основные адреса.
[Рекомендации Google по canonical](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

Sitemap успешно прочитан Google 23 сентября, обнаружено 493 страницы; живой XML
тоже содержит 493 URL. Число 512 в индексе не обязано совпадать с sitemap.
После публикации новых посадочных проверить их присутствие в XML, HTTP 200,
canonical, отсутствие noindex и доступность через внутренние ссылки.

### P2. Проверить оставшиеся группы по URL

Для 15 случаев другого canonical: сравнить объявленный и выбранный Google URL,
контент, внутренние ссылки, редиректы и sitemap. Для 55 просканированных, но
непроиндексированных страниц: сначала коммерчески важные, затем статьи;
проверить полноту ответа и отсутствие почти одинаковых шаблонных текстов.
Два soft 404 и четыре обнаруженных URL требуют индивидуальной инспекции.
Конкретные причины этих групп в этом аудите не установлены.

## План работ и контроль результата

1. **Ближайший выпуск:** опубликовать и проверить события; разобрать перечисленные
   404 с реальными заменами; диагностировать CLS. Критерий: нужные старые URL
   ведут на соответствующий контент, события поступают по одному ожидаемому
   действию, сдвиги воспроизводимо устранены.
2. **Следующий этап:** подготовить таблицу «запрос → одна основная посадочная»,
   начав с лазательных комплексов, горок, кинетикомоторных площадок, оборудования
   для детских садов и переработанного пластика при наличии подходящих товаров.
   Последние направления — гипотезы для проверки спроса, не прогноз объёма.
   Для каждой страницы добавить релевантные проекты и товары, обратные ссылки
   из карточек/проектов, преимущества и условия подбора. Не размножать одинаковый текст.
3. **После публикации:** проверить sitemap и отдельные URL в GSC; разобрать группы
   canonical/soft 404/неиндексируемых страниц. Не отправлять на проверку намеренные noindex.
4. **Через 28 дней:** сравнить одинаковые завершённые периоды. В GSC — небрендовые
   клики и показы по группе посадочных; в Метрике — органические страницы входа,
   контактные цели и материалы отдельно. Подписку не считать коммерческим лидом,
   автоцели не складывать с аналогичными ручными событиями.
